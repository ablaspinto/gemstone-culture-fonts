Fonts that need a custom import

Every option marked "In Shopify" is free and switches on in one click. These fonts are not in Shopify's font library, so we would have to upload the font files into the theme and add a little code. Paid fonts also need a web license bought from the font maker.

Avenir / Avenir Next (Option I)
Paid font from Monotype. Shopify removed it from its library. Needs a web license, then a custom import. Free alternative already in Shopify: Figtree (Option J).
Didot
Paid font. Needs a web license and a custom import. Free alternative already in Shopify: Bodoni Moda (Option F).
Cinzel
Free font, so no license cost, but it still needs a custom import. Alternative already in Shopify: Marcellus (Option H).
Quervia
Not in Shopify. Would need a custom import, and its web license terms need checking first.
Proxima Nova
Paid font (Mark Simonson Studio). Needs a web license and a custom import. Free alternative already in Shopify: Montserrat.
Helvetica
Paid font. Shopify removed it from its library. Needs a web license and a custom import. Free alternative already in Shopify: Arimo, which is nearly identical.
Optima
Paid font. Shopify removed it (as Optima Nova) from its library. Needs a web license and a custom import. Free alternative already in Shopify: Proza Libre.
